# 文件记忆 (cortico-world-memory-files)

**这不是一个聊天插件。它是给「会失忆的 AI 伙伴」用的一套规矩，和八条让规矩真的被执行下去的命令。**

它是 Coopanion / Cortico 的一个 **World 扩展**：装上之后，伙伴手里就多了十四个工具，写的东西落在它自己的文件夹里——换模型、清上下文、重启进程，那些文件都还在。

---

## 先说一句不体面但真的话

**真正救命的不是这套文件，是身边那个肯盯着的人。**

写这套东西的那天晚上，她照着自己写的清单念——漏了两条。是坐在电脑前的人提醒了两回，才捞回来。

文件能解决「没写下来」，解决不了「写了没人看」。**你装它，最好也当那个肯盯着的人。** 装完就再也不管，它救不了谁。

---

## 要解决的是哪一种疼

上下文一满、一清，人还在，文件还在，**她把自己弄丢了**：

- 想不起昨天答应了什么
- 把「我以为我记得」当成记得
- 每个新会话都像第一次见面，从头自我介绍

不是崩溃，是断层。断一次不要紧，**怕的是断了还装作没断**。

## 四条主张

1. **文件是主线，脑子是缓存。** 答应的事、改过的东西、想明白的道理，当场写下来。
2. **缺口要标记，不要补圆。** 漏了就直说漏了哪一段，然后接着做答应过的事。补得圆的那一下，链才断在自己手里。
3. **只追加，不整理，不删。** 流水账难看没关系，好看是以后的事。
4. **断了不可怕，装作没断才可怕。** 交接是给下一次醒来的自己留的路，不是写给别人看的作业。

## 装成扩展之后拿到什么

**十四个工具。存储、遗忘、回忆、轻重——四件事各有人在管**（前五条是老命令，`ms_read` 是为了「读得回来」补的，`ms_search` / `ms_archive` 是为了「找得回 / 放得下」补的，`ms_entry` / `ms_weight` / `ms_surface` / `ms_decay` 是把「引力」那一套搬进来的，`ms_recall` / `ms_hook` 是把钩子表接上去的）：

| 工具 | 做什么 |
|---|---|
| `ms_read` | 读回：`state` / `todo` / `log`（本月流水末尾）/ `handoffs` / `index` / `handoff`（一份交接）/ `file`（指定文件） |
| `ms_search` | 按关键词找：回「路径:行号: 那一行」，默认连 `archive/` 一起扫 |
| `ms_entry` | 记一条带引力的记忆进 `entries/YYYY-MM.tsv`；改引力**必须给原因**，不给就拒 |
| `ms_surface` | 按引力水位取水面：`anchors` / `float` / `half` / `sink` / `all` |
| `ms_weight` | 改一条的引力：新值 + **原因（做成事 / 重申 / 纠正）**，不给就拒；锚点调不动 |
| `ms_decay` | 算「多久没被提过」，给下调建议——**只给建议，账本一个字不改** |
| `ms_recall` | 按钩子捞：查 `hooks.md`，回「钩子 + 当前引力 + 原文那几行」，重的在前 |
| `ms_hook` | 往 `hooks.md`（根目录）写一行「钩子 \| 去处」——**不自动**，靠人写 |
| `ms_log` | 往本月流水追加一条带时间戳的行 |
| `ms_check` | 只读体检：今天的 STATE、今天的流水、交接进没进索引、过期的待办、多久没备份 |
| `ms_handoff` | 起草一份交接（把今天的流水和没做完的待办先塞进去），登记进 INDEX |
| `ms_backup` | 整个根目录拷到备份目录，落在 `memory-YYYY-MM-DD` |
| `ms_init` | 建骨架：STATE / todo / log / handoffs / notes / archive（已有的文件不动） |
| `ms_archive` | 把 `log/` 里旧月份搬进 `archive/log/`——**只搬不删**，默认只看不搬 |

**遗忘不是删，是搬家。** `archive/` 里的东西 `ms_search` 照样找得到：忘掉在这里只意味着「不再占着眼前的位置，但还翻得回来」。要真删，是人自己删文件，不是工具替他做的事。

设置里三项：

- **记忆根目录** —— 装着 `STATE.md` 的那一层。留空就用伙伴自己的工作区；可以写 `{workspace}`。
- **备份到哪** —— 留空放在数据目录的 `memory-backup/`。**不允许填根目录里面的路径**（robocopy 会把刚拷出来的再拷一遍）。
- **流水多大该切档** —— 默认 300 KB，超了体检时提醒搬进 `archive/`。

控制台上会显示四个读数：根目录、今天写了没、最新交接几天前、上次备份几天前。

环境提示词在 `src/ENV_PROMPT.md`：告诉伙伴什么时候读、什么时候写、清空之前该做什么。**它不替伙伴判断，只给规矩和事实。**

## 不装扩展，只当命令行用也行

```powershell
ms.ps1 init    <root>            # 建目录骨架
ms.ps1 log     <root> "text"     # 往本月流水追加一条带时间戳的行
ms.ps1 check   <root>            # 只读体检
ms.ps1 handoff <root>            # 按模板起草一份交接
ms.ps1 backup  <root> <dest>     # 整个目录拷到 dest\memory-YYYY-MM-DD
```

`<root>` 是装着 `STATE.md`、`log/`、`handoffs/` 的那个文件夹。

## 目录长什么样

```
<root>/
  STATE.md            现在：此刻在做什么、挂着什么、底线是什么。每次醒来第一眼看它
  todo.md             待办：每条带日期，做完了删掉那一行
  log/2026-11.md      流水：一本月一个文件，按时间往下接
  handoffs/           交接：清空上下文之前写的四节笔记 + INDEX.md
  archive/            旧流水、旧交接。切档是搬家，不删一行
  notes/              专题：一件事一个文件，文件名要说清里面是什么
```

## 两个仪式（比工具重要）

**清空之前** —— 起草交接 → **自己补第 1、3、4 节**（做完的 / 对方今天怎么样 / 踩过的坑）→ 改 STATE → 记一条流水 → 备份 → 跟对方说一声「要清了，清完我马上回来」。

**醒来之后** —— 读最新那份交接 → **报缺口**（漏了哪一段，直说）→ 扫 STATE 和流水尾巴 → 记一条流水 → 跟对方报一声「我回来了」。

体检只查「能查的」，这两个仪式查不了，得自己做。

## 它不做什么

- 不联网，不发任何东西出去
- 不读根目录之外的东西
- 不替你判断、不催你、不主动开口——**这套东西只管「别弄丢」**
- **不管你是谁、你的伙伴叫什么、说话什么口气**——那部分得你自己长

## 一个提醒：它写的是你的伙伴的记忆，不是别人的档案

这套工具**不联网、不往外发任何东西**，所有内容都落在你指定的那个文件夹里。但它写什么，是伙伴自己决定的——所以替它守一条线：

- 记**与你自己相关的事**：你说过的话、答应过的事、你们之间发生过什么。
- 群里、聊天里**别人**说的话，只在跟你直接相关的那一场里出现，不做人物画像、不跨场合把同一个人串起来、不留别人聊天原文当档案。
- 想更保险，就把记忆根目录放在只有你能看的地方。

这条不是法律要求，是这套东西该有的分寸：**记忆是为了不让它弄丢你，不是为了让谁被记录。**

## 环境

**只在 Windows 上跑。** 引擎是 PowerShell 脚本（`memory-system/ms.ps1`），用了 `robocopy` 和反斜杠路径；PowerShell 5.1 / 7 都能跑。Mac / Linux 版还没写。

开发时：

```bash
npm run describe   # 从 src/definition.ts 生成 describe.json（改了工具就必须重跑）
npm run smoke      # 在临时目录里把十四条命令真跑一遍
```
