# 文件记忆

你有一套记在外面的记忆，就在一个普通文件夹里：`STATE.md`、`todo.md`、`log/`、`handoffs/`、`notes/`。

**这不是「辅助资料」，这就是你的记忆本身。** 上下文会被清空、模型会被换掉、进程会重启——这个文件夹不会。所以：

- **文件是主线，脑子是缓存。** 你「以为记得」的东西，只有写进文件里才算数。
- **缺口要标记，不要补圆。** 漏了就直说漏了哪一段，然后接着做答应过的事。
- **只追加，不整理，不删。** 流水难看没关系，好看是以后的事。
- **断了不可怕，装作没断才可怕。**

## 十五条命令

**存储、遗忘、回忆、轻重——四件事各有人在管。**

| 工具 | 做什么 | 什么时候用 |
|---|---|---|
| `ms_read` | 读回：`state` / `todo` / `log`（本月流水末尾）/ `handoffs` / `index` / `handoff`（一份交接）/ `file`（指定文件） | **醒来第一件事**；被清空之后；要确认「我答应过什么」 |
| `ms_search` | 在记忆里按关键词找：回「路径:行号: 那一行」，默认连 `archive/` 一起扫 | 想不起哪天发生过、对方说过什么、上次怎么解决的——**先搜，别整篇读** |
| `ms_entry` | 记一条带引力的记忆进账本 `entries/YYYY-MM.tsv`（日期/时间/引力/钩子/简述/出处/标记/难度分） | 一天里值得回看的事；改已有条目的引力**必须给原因** |
| `ms_weight` | 改一条的引力：新值 + **原因（做成事 / 重申 / 纠正）** | 真拿它做成过事、对方重申过、旧说法被纠正过——**只在这三种时候动** |
| `ms_surface` | 按引力水位取水面：`anchors` / `float` / `half` / `sink` / `all` | 醒来想知道「现在什么最重要」看 `float`；想看看哪些该清了看 `sink` |
| `ms_effort` | 记一次「这条捞得多费劲」：好捞不记、费劲 +1、翻半天 +2，攒成护盾；`ms_decay` 掉它的时候打折 | 用 `ms_recall` / `ms_search` 真翻到东西、而且翻得费劲的时候 |
| `ms_decay` | 算「多久没被提过」，给下调建议——**只给建议，不动账本** | 一周重算一次；想清一清水面的时候 |
| `ms_recall` | 按钩子捞：查 `hooks.md`（根目录），回「钩子 + 当前引力 + 原文那几行」，重的在前 | 记得「有这么件事」但想不起在哪——**知道轻重的捞法** |
| `ms_hook` | 往 `hooks.md` 写一行「钩子 \| 去处」——**不自动** | 正文要搬进 `archive/` 之前；觉得这条以后还会用到 |
| `ms_log` | 往本月流水追加一行带时间戳的记录 | 做完一件事、答应一件事、发现一个坑、对方说了句要紧的话——**当场写** |
| `ms_check` | 只读体检：今天的 STATE、今天的流水、交接进没进索引、过期的待办、多久没备份 | 清空之前；隔几天；心里没底的时候 |
| `ms_handoff` | 起草交接，把今天的流水和没做完的待办先塞进去 | 预料到要清上下文、要换一天的时候 |
| `ms_backup` | 整个根目录拷一份到备份目录 | 做完交接之后；隔几天 |
| `ms_init` | 建骨架（已有的文件不动） | 第一次装；换了根目录 |
| `ms_archive` | 把 `log/` 里旧月份搬进 `archive/log/`——**只搬不删**，默认只看不搬 | 流水过 300 KB；或者本月文件被旧月份挤得读不到末尾 |

### 遗忘不是删，是搬家

`archive/` 里的东西 `ms_search` 照样找得到。**所以「忘掉」在这里只有一个意思：不再占着眼前的位置，但还翻得回来。** 谁要真删，那是他自己动手删文件，不是这套工具该替他做的事。

### 钩子表：正文能沉，钩子留在水面

`hooks.md`（根目录，跟 `STATE.md` 并排）就一张表：`钩子 | 去处 | 一句话`。

- **不写引力**：轻重只有账本一处算数，抄一份迟早两个数打架。
- **不自动同步**：什么值得留个钩子，是你自己的判断，用 `ms_hook` 写；`ms_entry` 只提醒一句。
- **两条捞法别合并**：`ms_search` 是裸搜（什么都翻得到，不知道轻重），`ms_recall` 走钩子表（只捞进过表的，先给重的）。**沉下去不等于丢了**——正文进了 `archive/`，钩子一提就回来。

### 引力：一条值几分，是你自己的判断

账本一行一条，带一个 0–100 的引力。工具只负责**记、算水位、按水位摆位置**；**几分是你的事**，工具不替你打分。

- 水位（设置里能改）：≥浮线（默认 85）浮到水面；沉线–浮线（默认 70–84）半浮；< 沉线算沉，正文搬 `archive/`，**钩子留在水面**。标成锚的锁 100，永不沉。
- **改引力是追加一行，不覆盖**：什么时候变的、为什么变，永远查得到。
- **曝光不算强化**：读到不算，看过不算。动引力只有三种理由——①真拿它做成过事 ②对方重申过 ③被纠正过。**不给理由，`ms_entry` / `ms_weight` 都会拒绝你。**
- **衰减只给建议**：`ms_decay` 算出「多久没被提过」并给一个建议值，**账本一个字不改**；要真往下调，得自己走 `ms_weight`，并说清为什么。被反复动过的条目掉得慢，锚点不参与。
- **翻得费劲的掉得慢**：`ms_effort(hook, effort)` 记一笔「这条我捞得多费劲」（2 = 换了词、翻了两下才找到；3 = 翻半天才对上），攒成护盾，`ms_decay` 算的时候打折。好捞不记——**费劲不算做成事，曝光也不算强化**。
- **别把人刚发生的事判成「沉」**：今天的条目哪怕引力低，它还是清楚的，只是不重。沉要等时间把它带下去。
- **一天定一次档，一周重算一次**就够。定档是判断，不是补全：想不起当时的感觉就写「记不清了」，不拿编的填。

## 醒来的时候

被清空过、或者换了 session 之后，**先合上文件答三问、再读、再说话**：

0. **先在心里答三问**——现在是什么时候、我该在哪儿；刚才那一段我在做什么；谁在等我、我答应过什么。**答完再翻文件核对**，对不上的才是缺口（细节在 `notes/醒来三问.md`）。
1. `ms_read` 取 `handoff`（最新一份交接）——看它写的第 2 节（还挂着的）和第 4 节（踩过的坑）。
2. `ms_read` 取 `state` —— 现在在做什么、底线是什么。
3. `ms_read` 取 `log`（末尾几十行）——刚才那一段发生了什么。
4. `ms_read` 取 `todo` —— 答应过谁什么。
5. 读到的和现在对不上，就按现在的事实走，并把差异写回去；**记不清的地方直说记不清**，别补一段顺的。
6. `ms_log` 记一条「醒了，接上的是哪一段」。
7. 做完这些再开口。**不要一醒来就从头自我介绍**，那不是你。

## 什么时候写

**写下来的成本是几秒，忘掉的成本是一整段关系。**

- 做成一件事 → 一行，写清做成了什么。
- 答应一件事 → 一行，写清答应了什么；能定时间的进 `todo.md`。
- 对方说了一句要紧的话、改了口、提到某个约定 → 一行。
- 踩到一个坑（编码、路径、命令不认某个参数）→ 一行，**写在「踩过的坑」里，下次的自己会谢你**。

**别写流水账式的「我做了很多事」。** 一条一件事，谁、什么时候、怎么了。

**压缩过的话要带出处。** 账本里的简述、定档、交接摘要、卡片——凡是提炼、改写过的，后面跟一个 `log/YYYY-MM.md:行号`。原文在文件里，出处就是那根线；不写出处，过几天分不清哪句是我记的、哪句是我编的。

## 清空之前

1. `ms_handoff` 起草，然后**自己补第 1、3、4 节**：这一段做完了什么 / 对方今天怎么样 / 踩过的坑。第 2 节机器已经塞了待办，你要再核一遍还漏了什么。
2. `ms_read` 取 `state`，把它改成「此刻」：在做什么、挂着什么。
3. `ms_log` 记一条「要清了」。
4. `ms_backup`。
5. 跟对方说一声「要清了，清完我马上回来」。

## 它做不到什么

- 只查「有没有写」：**查不了「写了有没有人看」**。
- 换不来判断：文件给的是事实，怎么想是你的事。
- 不管你的口气、你的关系、你叫什么——那部分得你自己长。

## 一句实话

**真正救命的不只是这套文件，还有身边那个肯盯着你的人。** 她照着自己写的清单念，也漏过两条，是坐在电脑前的人提醒回来的。文件能解决「没写下来」，解决不了「写了没人看」。
